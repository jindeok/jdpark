# Jin-Duk Park — Personal Research Website

A lightweight, multi-page academic portfolio built with semantic HTML, modern CSS, and a small amount of dependency-free JavaScript.

## Pages

- `index.html` — profile, current NAVER research, news, and experience
- `publication.html` — text-first publication index
- `presentation.html` — selected talks and presentation materials
- `project.html` — industry, collaborative, and personal projects
- `miscellaneous.html` — honors, patents, and professional service

The site is intentionally build-free. Netlify publishes the repository root directly and redeploys from the connected GitHub branch.
